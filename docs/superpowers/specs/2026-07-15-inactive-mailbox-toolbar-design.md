# 失活邮箱顶部操作入口设计

## 目标

让用户无需在账号列表中寻找入口，即可从已展开的顶部账号操作栏检测并批量删除明确失活的邮箱。

## 界面

- 在顶部“删除已选”附近显示“检测失活”按钮。
- 检测完成后显示“删除失活（N）”，`N` 为当前明确失活的账号数。
- 检测运行期间按钮显示“检测中”并禁用删除操作。
- 没有明确失活账号时，“删除失活”保持禁用。
- 左侧账号列表仍显示失活数量和现有批量操作，避免移除既有入口造成回归。

## 数据与安全

- “检测失活”调用现有 refresh token 保活流程。
- 仅凭证明确失效、账号禁用或账号不存在被判定为失活。
- 网络超时、限流、IMAP 错误和权限不足不进入删除名单。
- “删除失活”在点击时重新计算名单，显示邮箱预览并要求二次确认，然后复用事务性批量删除接口。

## 验证

- 语法检查与差异格式检查。
- 账号健康判定单元测试。
- 批量删除接口集成测试。
- 确认顶部按钮存在、禁用条件和事件绑定正确。
