# 邮箱聚合平台 · 前端优化版（演示）

一个成熟、克制、高信息密度的桌面端前端，覆盖三个核心页面：**统一收件箱、邮箱账户管理、批量导入**。
沿用项目现有技术栈（原生 JS + CSS，无框架、无构建、无新增依赖），与现有产品完全独立，**不改动 `public/`、`server.js` 或任何后端接口**。

## 运行

```bash
node ui-demos/serve.js
# 打开 http://127.0.0.1:4321/ui-demos/
```

端口可用 `UI_DEMO_PORT` 覆盖。三个页面为前端 hash 路由：

- 统一收件箱：`http://127.0.0.1:4321/ui-demos/#/inbox`
- 邮箱账户管理：`http://127.0.0.1:4321/ui-demos/#/accounts`
- 批量导入：`http://127.0.0.1:4321/ui-demos/#/import`

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 入口 |
| `styles.css` | 设计系统 + 三个页面全部样式 |
| `data.js` | 稳定的模拟数据（约 286 个账号、邮件、分组、服务商，确定性生成） |
| `app.js` | 应用外壳 + hash 路由 + 三个视图 + 交互 |
| `serve.js` | 独立静态服务器（不加载真实凭证、不连 IMAP） |

## 设计方向

克制专业、高密度、桌面优先。发丝边框而非阴影；单一靛蓝强调色只用于选中/主操作/链接/焦点；小号紧凑字号；列表用行而非卡片；状态用「圆点 + 文字」而非仅颜色。**无紫色渐变、无玻璃拟态、无巨型标题、无大数据卡。**

## 说明

- 全部数据为**杜撰**，不连接任何真实邮件服务，不发送/删除真实邮件。
- 缺后端支持处（导入进度、连接测试、回复发送）为模拟交互，界面已注明「演示」。
- 现有产品（`/` 处的凭证/验证码工具）保持不变；如需将本设计并入产品，可参照 `FINAL_RECOMMENDATION.md` 的实施路线。
